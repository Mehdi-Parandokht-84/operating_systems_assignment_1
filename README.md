<h2>🏭 معرفی دستگاه</h2>
<p>
<strong>دستگاه انتخابی:</strong> کنترل‌کننده صنعتیِ خط تولید؛ دستگاهی که با دریافت اطلاعات حسگرها و ارسال فرمان به تجهیزات، فرایند تولید را کنترل می‌کند.
</p>

<h2>⚙️ ۱. نوع سیستم‌عامل</h2>
<p>
برای این دستگاه، <strong>سیستم‌عامل بلادرنگ (RTOS)</strong> مناسب است؛ زیرا باید اجرای وظایف کنترلی را در مهلت‌های زمانی مشخص تضمین کند.
</p>

</p>
