تکلیف 1 سیستم‌عامل
بررسی سیستم‌عامل یک کنترل‌کننده صنعتی
دستگاه انتخابی: کنترل‌کننده صنعتیِ خط تولید

۱. نوع سیستم‌عامل
برای این دستگاه، سیستم‌عامل بلادرنگ (RTOS) مناسب است؛ زیرا باید رویدادها را پردازش کند و در مهلت زمانی مشخص به آن‌ها پاسخ دهد.

۲. مهم‌ترین وظایف سیستم‌عامل
دریافت داده‌های حسگرها، زمان‌بندی اجرای برنامه‌های کنترلی، مدیریت پردازنده و حافظه و فراهم‌کردن ارتباط با تجهیزات برای ارسال فرمان‌های کنترلی.

۳. مهم‌ترین ویژگی
پاسخ‌گویی قابل‌پیش‌بینی و به‌موقع مهم‌ترین ویژگی است؛ زیرا حتی تأخیر کوتاه در اجرای برخی فرمان‌ها می‌تواند عملکرد خط تولید را مختل کند.

۴. پیامدهای انتخاب سیستم‌عامل نامناسب
انتخاب نامناسب ممکن است باعث تأخیر در کنترل تجهیزات، کاهش کیفیت محصولات، توقف خط تولید و حتی آسیب به دستگاه‌ها یا کارکنان شود.
